TaskMaster.md 中 Event capability 的协议对齐

必须实现的协议：
schema_version 固定为 1。
Status 只有 working、waiting_input、completed、error；idle 不落盘。
EventKind 只有 session_started、work_started、progress、input_required、turn_completed、failed、session_ended、cleared。
Source 只有 hook、notify、manual、log。
Capability 只有 full、completion_only、manual，并且 Event 必填 capability。
TTL：working 15 分钟，waiting_input 8 小时，completed 2 分钟，error 8 小时。
Reducer 签名为：func Reduce(old *domain.SessionSnapshot, event domain.Event) (domain.ReduceResult, error)。
Reducer 是纯函数，不调用 time.Now，不做文件、网络、日志或通知 I/O，不修改 old。
SessionEnd 和 Cleared 返回 Next=nil。
相同 event ID 幂等，revision 不增加。
事件比旧 updated_at 早超过 2 秒时返回 ErrStaleEvent；刚好早 2 秒必须接受。
failed 使用脱敏后的 message 计算 SHA-256 error fingerprint，并正确设置 ErrorChanged。
所有字符串长度按 Unicode code point 校验，不按 UTF-8 字节数。
